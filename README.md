# FitnessBikeRecorder + Windows PC連携

AndroidでフィットネスバイクのBLEデータを記録し、同じLANのWindows PCを漕いでいる状態に応じて暗くするアプリです。

## 初回設定

1. PC用ZIPをすべて展開して、`Install.cmd`を実行します。管理者権限は不要です。Windowsへのログイン時の自動起動も登録されます。
2. Android用APKをスマホにインストールして起動し、必要な権限を許可します。既存アプリと署名が違う場合は上書きできません。既存データを残す場合は、元の署名鍵でこのソースをビルドしてください。
3. PCとスマホを同じLANに接続します。PCは同じルーターへの有線接続でも構いません。
4. スマホの「PC連携」で接続コードを確認します。
5. PCの通知領域にある自転車アイコンを右クリック →「設定」でスマホを選択し、接続コードを入力して保存します。
6. スマホから通常どおりバイクへ接続します。以降、登録したスマホが見つかるとPCが自動接続します。

自転車アイコンはWindowsの通知領域の「隠れているインジケーター」に入る場合があります。必要ならWindowsのタスクバー設定で常に表示してください。

## 動作

- 停止を検出して5秒待ち、**10秒で滑らかに暗くなります**。最大の暗さは80%です。
- 漕ぎ始めると約1秒で戻ります。待機時間・暗転時間・最大の暗さは設定で調整できます。
- 半透明の黒いウィンドウを各モニターに重ねます。クリックとキーボード入力を妨げず、フォーカスを奪いません。モニター本体の輝度設定を変更しません。
- 右クリックから30分停止、1時間停止、今すぐ再開、自動起動の切り替え、設定、終了ができます。
- 停止の時間は選択した時点から数えます。停止を選び直すと、その時点から再計算します。停止終了後は5秒の猶予から再開します。
- スマホやバイクの切断、5秒以上古い通信・BLEデータ、回転数も出力もないデータの場合は、暗転を解除します。
- 設定を開いている間も暗転を解除します。モニター追加・切断やPCのスリープ復帰にも対応します。
- PC側は通常のメインウィンドウを表示しません。ログイン前に動くWindowsサービスではありません。

## 接続できない場合

- スマホのアプリを起動し、PC連携ダイアログにWi-Fiの接続先が表示されるか確認してください。
- Windowsがファイアウォールの許可を求めたら、プライベートネットワークを許可してください。
- 自動検出だけが失敗する場合、PC設定の手動接続欄に、スマホに表示された端末IDとIP:ポートを入力できます。IPやポートが変わった場合は更新が必要です。
- 必要なら同梱の`EnableDiscoveryFirewall.ps1`を管理者として実行してください。インストール済みアプリについて、プライベートネットワーク・ローカルサブネットのUDP 5353だけを許可します。
- ゲストWi-Fiの端末分離、VPN、ルーターのマルチキャスト制限で接続できない場合があります。
- スマホの画面を消す場合も、Androidのフォアグラウンドサービスで共有します。メーカーの省電力設定が停止させる場合は、FBRecoのバックグラウンド動作を許可してください。

## 対応範囲と注意点

- PC版：Windows 10/11 x64。配布用EXEは.NETランタイム同梱で、別途.NETをインストールする必要はありません。
- Android：既存アプリと同じAndroid 8.0以降。IPv4のWi-Fiネットワークを使います。
- 排他的フルスクリーンのゲーム、UACやロック画面などは暗くできない場合があります。ゲームはボーダーレス表示で確認してください。
- HDRや画面キャプチャ・共有への映り方は環境によって異なります。
- 運動状態だけをLAN内で共有し、クラウドには送りません。接続コードは通信に送らず、HMAC-SHA256で接続と各状態メッセージを認証します。通信内容自体は暗号化していません。
- PCの接続コードはWindowsのユーザーごとのDPAPIで保護して保存します。Android側の接続情報はバックアップ対象から除外しています。
- `Uninstall.cmd`は自動起動とインストール済みファイルを削除します。ペアリング設定は`%LOCALAPPDATA%\FitnessBikeRecorderPC`に残します。追加したファイアウォール規則は必要に応じてWindowsの設定で削除してください。

## 開発と検証

Android：JDK 17/21、Android SDK 35、Gradle wrapperを使用します。`local.properties`にSDKパスを設定してください。

```powershell
./gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

PC：.NET 10 SDKを使用します。

```powershell
dotnet build desktop/FitnessBikeRecorder.PC -c Release
dotnet run --project desktop/FitnessBikeRecorder.Tests -c Release
dotnet publish desktop/FitnessBikeRecorder.PC -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o desktop/dist
```

テストは、暗転・復帰の時間、停止・不明データの扱い、Android/PC共通の署名ベクトル、改ざんとリプレイ拒否、実際のWebSocketでのタイムアウト・再接続、ウィンドウのマウス透過・非アクティブ化を確認します。実機のBLE接続、Wi-Fi自動検出、画面オフ時の維持、HDRやゲームとの相性は手元の端末で確認してください。

通信仕様は[docs/pc-link-protocol.md](docs/pc-link-protocol.md)にあります。
